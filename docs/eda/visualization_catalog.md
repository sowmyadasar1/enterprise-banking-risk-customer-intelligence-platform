# Visualization Catalog

This catalog serves as a directory of the key visualizations generated during the EDA phase. All files are located in the `visualizations/` directory.

## 1. Marketing Analysis Visualizations
- **`marketing_response_by_segment.png`**: Bar chart detailing the conversion rates across different customer segments (Retail, SME, Corporate, High Net Worth).
- **`marketing_campaign_performance.png`**: Count plot comparing the absolute number of responses (success/fail) across different marketing campaigns.

## 2. Executive Summary Interactive Visualizations (HTML)
- **`executive_regional_performance.html`**: Interactive Plotly bar chart visualizing total revenue across major global regions. Color-coded by revenue scale.
- **`executive_product_profitability.html`**: Interactive Plotly treemap displaying profit margins for various product offerings. Size and color denote profitability.
- **`executive_risk_profile.html`**: Interactive Plotly scatter plot mapping default rates against customer segments, providing a clear visual of risk concentration.

## Usage Notes
- PNG files are suitable for embedding in static reports and presentations.
- HTML files should be opened in a modern web browser to utilize hover and zoom interactivity. They are ideal for executive dashboards.
