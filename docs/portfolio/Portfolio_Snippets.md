🚀 **Excited to share my latest project: Enterprise Banking Risk & Customer Intelligence Platform**

I spent the last several weeks building a production-grade, end-to-end data and machine learning platform that simulates a modern retail bank's core intelligence layer.

**What it does:**
📊 Processes 5M+ banking records through a Medallion Architecture ETL pipeline (Bronze → Silver → Gold)
🏗️ Loads data into a Kimball Star Schema data warehouse
🤖 Trains 4 ML models: Fraud Detection (0.99 AUC), Loan Default Prediction, Customer Segmentation, Revenue Forecasting
🚀 Serves predictions via a FastAPI REST API with sub-10ms latency
📦 Containerized with Docker Compose (API + MLflow + PostgreSQL)
🔄 Automated with GitHub Actions CI/CD

**Tech stack:** Python, pandas, scikit-learn, XGBoost, statsmodels, FastAPI, MLflow, Docker, PostgreSQL, Power BI, GitHub Actions
