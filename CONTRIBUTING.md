# Contributing

Thank you for considering contributing to the Enterprise Banking Risk & Customer Intelligence Platform!

## How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/yourusername/enterprise-banking-intelligence.git
cd enterprise-banking-intelligence
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Make Changes
- Follow existing code style and naming conventions.
- Add type hints to all function signatures.
- Include docstrings for new functions and classes.
- Write tests for new features.

### 5. Run Tests
```bash
make test
```

### 6. Submit a Pull Request
- Describe your changes clearly.
- Reference any related issues.
- Ensure all tests pass.

## Code Standards
- **Python**: PEP-8 compliant (enforced by `flake8`).
- **Commits**: Use conventional commit messages (`feat:`, `fix:`, `docs:`, `refactor:`).
- **Documentation**: Update relevant docs if your change affects behavior.

## Reporting Issues
Use the GitHub Issues tab with the provided templates for bug reports and feature requests.
